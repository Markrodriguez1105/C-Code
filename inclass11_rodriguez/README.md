# C++ Integrated Tool

This project is a C++ integrated tool that combines functionalities for character mapping, token scanning, keyword recognition, and symbol table management. It allows users to process source code from an input file and presents the results in the console or writes them to an output file.

## Project Structure

```
cpp-integrated-tool
├── src
│   ├── main.cpp
│   ├── CharMap.h
│   ├── Scanner.h
│   ├── KeywordList.h
│   ├── SymbolTable.h
├── input.txt
├── output.txt
└── README.md
```

## Files Description

- **src/main.cpp**: The driver program that integrates the functionalities of the CharMap, Scanner, KeywordList, and SymbolTable classes. It allows users to choose between generating token streams, listing keywords, generating a symbol table, or executing all functionalities against the input source code read from `input.txt`. The results are presented in the console or written to `output.txt`.

- **src/CharMap.h**: Defines the CharMap class, which identifies the type of characters. It includes an enumeration `CHAR_TYPE` for different character types (WHITESPACE, LETTER, DIGIT, SPECIAL, QUOTE, ERROR, EOF_TYPE) and a method `type(char)` that returns the character type.

- **src/Scanner.h**: Defines the Scanner class, responsible for tokenizing input strings. It includes an enumeration `TOKEN_CODE` for different token types (ERROR, WORD, NUMBER, EOF_TOKEN) and methods such as `accept(string)`, `next_token()`, `token_string()`, and `lexeme_string()` for processing input and retrieving tokens.

- **src/KeywordList.h**: Defines the KeywordList class, which manages a list of keywords. It includes an enumeration `KW_CODES` for different keyword codes (NOT_FOUND, KW_FALSE, KW_NONE, etc.) and a method `search(string)` that performs a binary search to find keywords in the list.

- **src/SymbolTable.h**: Defines the SymbolTable class, which manages symbol entries. It includes a struct `STEntry` for storing lexeme, data type, and value attributes, and methods `insert(string, string, string)` for adding entries and `search(string)` for finding entries in the symbol table.

- **input.txt**: Serves as the input source code for the driver program. It contains the code that will be processed by the lexer.

- **output.txt**: Used to store the results generated by the driver program, such as token streams, keyword lists, and symbol tables.

## Compilation and Execution

To compile and run the program, follow these steps:

1. Open a terminal and navigate to the project directory.
2. Compile the source files using a C++ compiler, for example:
   ```
   g++ -o cpp-integrated-tool src/*.cpp
   ```
3. Run the compiled program:
   ```
   ./cpp-integrated-tool
   ```
4. Follow the prompts to choose functionalities and view results in the console or output file.

## Functionalities

- **Token Generation**: Process the input source code to generate a stream of tokens.
- **Keyword Recognition**: Identify and list keywords present in the input code.
- **Symbol Table Management**: Create and manage a symbol table for the identifiers in the input code.
- **Continuous Execution**: Users can invoke functionalities individually or continuously based on their needs.

This project serves as a foundational tool for understanding lexical analysis and symbol management in programming languages.
